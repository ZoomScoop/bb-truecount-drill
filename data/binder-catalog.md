# Binder Catalog — Card Collection OS

Running catalog of the physical binder, logged from page screenshots.

## Numbering convention
- **catalog_number**: sequential in reading order across the whole binder (1, 2, 3, …).
- **page**: which binder page / screenshot the card is on (1-based).
- **slot**: grid position on that page, RowColumn (e.g. `R1C1` = top-left, `R2C3` = middle row, 3rd column).
- Card backs are ignored unless they're the only source of a card's info.

This file is the interim source of truth until the Supabase database is live;
columns map cleanly to the `cards` table for a later one-shot import.

## Pricing pass
First pass = identify + number + locate every card. Deep price/comp research is
done on the cards worth it (rookies, parallels, numbered, stars, anything that
isn't bulk base), with keepers flagged in `notes`. Say the word to price any
specific card or the whole page in detail.
